# delta-sensitivity-tool
# 🎯《三角洲行動》FOV 100 靈敏度校準工具  無需安裝，開啟瀏覽器即可測試手遊靈敏度！  ### ✨ 核心功能 - **模擬測試**：提供拉槍定位與跟槍追蹤測試。 - **Touch Scale 換算**：支援螢幕採樣率（如 Y700 的 240Hz）與靈敏度計算。 - **校準建議**：自動分析拉槍「過頭」或「不到位」並給予建議。  ### 🧮 算式 (帶入腰射靈敏度) `Touch Scale = 0.45 × (腰射靈敏度 ÷ 50)` *(請四捨五入至最接近的 0.05 刻度，例：0.585 填 `0.60`)*  --- *MIT 開源授權，AI (Claude) 協助開發，免費供社群交流測試使用。*
